# 혜인·진우 가계부

GitHub Pages로 올리는 정적 사이트예요. 데이터는 청첩장과 같은 Firebase 프로젝트(Firestore)에 저장되고,
등록된 구글 계정 두 개로만 열 수 있어요. 가계부 기록은 이 저장소에 들어가지 않아요.

- 주소: https://money.hin-wedding.site
- 파일
  - `index.html`, `styles.css`, `app.js` — 화면과 동작
  - `categorizer.js` — 지출 자동 분류(우리 기록으로 학습하는 분류기, 브라우저 안에서만 계산)
  - `firebase-config.js` — 청첩장과 같은 Firebase 설정(공개돼도 되는 값)
  - `CNAME` — GitHub Pages 사용자 도메인

## 데이터가 저장되는 곳 (Firestore)

| 컬렉션 | 내용 |
| --- | --- |
| `ledgerMonths/{YYYY-MM}` | 달별 수입 목록, 고정비 합계, 파킹통장 잔액, 투자 계좌 |
| `ledgerExpenses/{id}` | 유동비 한 건 (내용, 금액, 분류, 누가, 메모) |
| `ledgerFixed/{id}` | 고정비 항목 (금액, 어느 통장, 종류, 대출 원금·기간) |

접근 규칙은 Firebase 콘솔의 Firestore 규칙에서 관리해요(이 저장소에는 넣지 않아요).

## 자동 분류가 배우는 방식

- 지출 내용을 단어와 글자 두 개씩 묶음으로 나눠서, 지금까지 어떤 분류로 기록됐는지 세어 확률을 계산해요.
- 분류를 직접 고치면 그 기록은 3배로 더 크게 배워요.
- 기록이 적은 새 단어는 기본 키워드(주유→교통, 올리브영→꾸밈 등)를 힌트로 써요.
- '흐름' 탭의 **AI 분류 점검**에서 예전 기록 중 다르게 분류된 것 같은 항목을 한 번에 고칠 수 있어요.
